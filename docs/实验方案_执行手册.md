# Idea 02：专家分歧下，学习“该修什么标注”
## 可交给研究生执行的实验方案（研究计划，未开展真实训练）

版本：1.0；方案核验日期：2026-11-07。  
工作标题：Learning Which Annotation to Improve under Expert Disagreement in Weld Inspection。  
唯一研究问题：在固定专家人时内，联合选择哪一个焊缝图像案例、购买哪一种标注改进动作，能否比强主动学习基线更有效降低独立评估集上的检测风险？

本包的 CPU 合成实验执行实际的 NumPy 学习、动作后重训和评估，用于检查算法与数据流是否运行正确；所有专家、图像、动作成本和动作结果均为模拟。它不证明焊缝应用有效。本方案中所有真实样本数、工时、效应和周期均为待预实验修订的计划量。结果表用 NA 留空，不存在已完成真实专家研究或真实检测器训练的含义。

阅读顺序：本手册 → 专家分歧与动作标注规范 → 数据获取与防泄漏 → 统计分析计划 → 真实模型与 RapidX 接入 → README 的软件复现命令。文献编号对应 references/可核验参考文献.md；正式统计配置见 configs/real_protocol.yaml，原型参数见 configs/smoke.yaml。

## 1. 论文主张、可证伪性与创新边界

### 1.1 要回答的具体问题

现有标注是否可靠、某一图像是否难识别、某一种操作是否值得专家时间，是三个不同问题。图像难识别可能因为边界不清、漏掉小指示、类别定义冲突、显示设置不合适，也可能因为单幅图像不包含判别所需信息。统一要求“再标一遍”会混合不同成本和收益。本研究将真实分歧拆解为存在性/漏标、几何边界、类别和信息不足，在同一预算下实测六类动作的下游收益，再学习分配专家时间。

目标函数不是让专家意见变得一致，也不是让训练集标签看起来整齐，而是改善一个固定检测任务的独立评估结果。即使一次复核减少了标签熵，也可能没有降低检测风险；此时它的下游奖励为零或负。少数专家意见可能包含关键小指示，不能把“不同意多数”直接编码为噪声。多数表决只能形成一个可追溯的训练标签候选，不能自动成为测试真值。

### 1.2 与已有工作的关系

焊接标注质量研究 [R01] 已分析人工制造的位置、类别等标注错误与检测性能的关系。因此“标注质量影响焊接检测”与“位置标注可能重要”都不是新贡献。该工作不能直接回答自然专家分歧中，一个具体案例该修边界、补漏标、改类别还是增加信息，也没有替代本研究的随机动作与成本试验。

更早的 ActiveLab [R04] 已联合考虑新样本标注与旧样本重标；近期 Deep Active Re-Labeling [R08] 也将部分预算用于修复已标注数据。因此“首次让主动学习可以重标”“首次在新旧样本之间选择”不可写入论文。NUTMEG [R05] 提醒我们区分有意义的分歧与噪声；它在语言任务的构建不等于已经解决焊缝像素边界问题。Adaptive Labeling [R06] 面向评估不确定性而非本方案的训练集改进收益，提供预算规划与选择偏差方面的启发。Minority Reports [R07] 提供注释成本与重复人力配置的相关先例；其预印本状态必须保留。标注饱和研究 [R09] 表明所需专家数量依赖目标指标，不能据此把语言数据中的人数结论直接套到焊缝。

拟成立的贡献是一个经验证的组合：真实焊缝专家分歧的动作分类与完整人时账本；在可用动作、信息不足和预算约束下学习下游收益/成本；用独立专家参考和前瞻预算对比检验其收益。通用主动学习、上下文 bandit、岭回归、逆倾向加权和分歧指标本身均是工具，不宣称原创。

### 1.3 预注册假设与失败条件

| 编号 | 假设 | 主比较与判断 |
|---|---|---|
| H1 | 同样 60 专家人分钟，学习动作的策略降低风险曲线面积 | Full − uncertainty_per_minute 的 nAUC；95% 成对区间上界 < 0，且点估计 ≤ −0.02 才称同时具有统计与预设实际意义 |
| H2 | 效率收益不以更多关键指示漏检为代价 | 关键指示图像漏检率差上界 < +0.02；此 2 个百分点只是研究预设，不是安全容许值 |
| H3 | 区分边界、类别、漏标与信息不足比单一分歧标量更有用 | Full 对合并分歧、去除专家分歧特征等消融的 nAUC；按探索性多重比较报告 |
| H4 | 收益不能完全由便宜动作或某一固定动作解释 | 与共享成本模型的不确定性基线、固定动作及无成本消融比较 |
| H5 | 政策不是只适应同一专家组/设备的习惯 | 留一专家组、留设备结果与交互作用；样本不足时仅描述，不作普适性结论 |

H1 为唯一主要优效终点。H2 为预注册保护性次要终点，若事件数太少导致区间过宽，应判“安全代理上的证据不足”，不判通过。H3—H5 是机制和适用范围证据。论文成功不能只依据一个随机种子、一个时间截点或一个性能最好的专家组。

以下任一情况限制或否定主要主张：Full 未优于强 uncertainty_per_minute；只有共识标签上的 mAP 提升，独立评估风险没有改善；成本优势只在不计复核/失败/准备时间时存在；收益主要来自合成场景硬编码的动作规律；跨设备/跨专家出现方向反转；动作样本没有重叠支持、成本误差过大或真实参考分歧太高。无显著差异不等价于证明等效，要给出区间与可排除效应。

## 2. 研究对象、单位及任务定义

### 2.1 固定任务

第一阶段限定二维焊缝射线图像的指示检测与分割/定位；只使用选定图像和允许的采集元数据。焊接工艺、材料厚度、影像成像方式、类别字典在采集前固定。不要把同一小样本实验中无关的外观相机、超声和 CT 混成一个任务。本方向研究专家标注决策，不依赖 Weld-LLaVA 或生成式解释，也不包括“每句话的图像证据”实验。

采用“可见指示类别”与“工程缺陷判级”两层定义。若没有适用标准、尺寸标定、厚度、工艺和独立工程依据，只能报告图像层面的检测代理指标。不得把线状形态自动等同裂纹，不得把模型全背景称为工程可接受。真实类别及关键类名单由专家在盲态锁定，合成类 1 圆形、类 2 线形只用于软件检查。

### 2.2 独立单位

最小统计分组是物理试样/焊缝，不是图像切块、像素、缺陷实例或专家读片次数。同一试样的多投照、多次曝光、相邻切块、增强版本、重复导出必须共享分组键。在现场无法区分“同一试样”和“同一焊缝”的情况下使用更保守的联合分组。设备、来源单位、采集批次用于更高层泛化与敏感性分析。

动作单位是一例可执行的图像任务；主实验一个案例最多购买一次动作。一个案例可以有多张关联视图，但原图与衍生图不可跨数据角色。若以后允许“先补漏标，再修边界”，第二步的状态已被第一步改变，必须重新定义顺序策略和记录概率；本包不把单步动作模型冒充已实现多步因果规划。

### 2.3 角色分离

| 数据角色 | 允许用途 | 明确禁止 |
|---|---|---|
| seed_train | 初始检测器训练与固定初始标签 | 作为独立测试 |
| policy_train | 随机动作日志、收益/成本模型拟合 | 用其结果冒充前瞻比较 |
| policy_val | 动作模型超参、策略规则定型 | 合并进拟合后再当验证 |
| reward | 动作前后重训的独立开发奖励 | 选择最终论文效果后反复改指标 |
| acquisition_pool | 冻结策略的前瞻采购候选池 | 暴露未购买动作的修订结果 |
| detector_val | 检测阈值、检测器方案选择 | 给策略提供测试反馈 |
| test | 锁定主试验评估 | 调动作、调阈值、选种子 |
| device_test | 设备独立外部检查 | 随机拆图后仍宣称设备外推 |

reward 是开发资源，其参考标签也需要专家成本；它不等于最终 test。代码采用角色检查，实际研究还必须检查物理来源映射。具有相同像素而不同文件名的图像，也必须归并。

## 3. 数据获取与样本计划

### 3.1 三类来源

公开 SWRD [R02] 可作为真实图像起点，论文确认有多边形标注和射线图像。它不自动提供本研究要求的三专家独立读片、自然分歧原因、动作时间或试样/设备键。先取得当前数据许可、下载版本和来源映射，核对原图与滑窗切片关系。没有物理分组元数据时，只能作为预训练/可行性数据，不能声称完成严格设备独立测试。RapidX [R03] 是可考虑的标注工具，不是预先存在的本研究动作日志数据库。

合作单位的连续病例能提供独立物理键、设备和采集批次，优先用于锁定测试与前瞻候选池。只获取已授权科研使用的历史图像或单位正常流程产生的图像，研究生不自行操作射线设备。重复成像动作只通过合规现有服务与独立协议实施；无此条件时将该动作标为不可用，并将结论限定于五类标注操作。

合成数据仅用于通路验证、已知真值的误差检查与敏感性分析。它可以可控改变边界、漏标、类别和画质，但不可替代自然专家分歧；必须单列图表并注明 synthetic。不能从生成器的噪声类型直接生成真实策略的“最佳动作”标签。

### 3.2 双队列，避免只在难例上宣称总体收益

建立连续入组队列与分歧富集队列。连续队列按时间/批次预设规则抽样，用来描述实际分歧率、类别分布和图像质量。富集队列从独立初读中抽取边界/类别/漏标/信息不足分歧，用于学习动作机制与保证每类动作有机会被观测。每例记录其进入队列的原因与抽样概率；论文分别报告，不能把富集队列风险解释为现场总体风险。

约 300 个分歧案例是原始 Idea 的可执行研究起点，不是功效保证，也不是已收集的数据。建议其中 240 例用于 policy_train、60 例用于 policy_val，全部以独立试样为单位。另设约 60 个未标注、预先采集的案例评估 new_image 动作；未标注案例与已有多专家标签的案例具有结构性差异，不能把它们当作同一病例可交换的六个处理。

### 3.3 资源充足版本的规划数量

下表是一套可审计的规划，不要求在没有资源时强行凑数。预实验需按真实分歧率、单位时长和可用动作重新核定；调整在看 test 结果之前完成。

| 角色 | 计划独立试样数 | 说明 |
|---|---:|---|
| seed_train | 400 | 可复用合法历史单专家标签，三专家子集需单列 |
| policy_train | 288 | 240 分歧例 + 48 未标注例 |
| policy_val | 72 | 60 分歧例 + 12 未标注例 |
| reward | 100 | 独立参考开发集，必要时按试样再拆奖励拟合/验证 |
| acquisition_pool | 240 | 前瞻池；每个重复是否重新抽池必须预登记 |
| detector_val | 100 | 固定阈值/训练方案 |
| test | 200 | 主测试物理试样；包含连续队列分布 |
| device_test | 100 | 不同设备/单位，初期为探索性外部队列 |
| 合计 | 1500 | 仅计划；不是 1500 张切块或 1500 次专家读取 |

若只有 300 例总资源，应把目标降为机制可行性和动作日志研究：保留不可触碰的独立小测试集，减少模型复杂度与结论强度，不宣称充分验证 H1/H2。每种动作至少观察若干成功、无效和失败例；计划约 300 个分歧例平均分到五种可用动作后仅几十例，复杂深度策略容易过拟合，初始采用低容量岭回归是有意约束。动作间样本不平衡需报告，不能补造均匀日志。

### 3.4 主测试样本量

规划效果为 nAUC 降低 0.02，成对试样差的标准差假设 0.08，双侧 α=0.05、功效 0.80。正态近似 n≈((1.96+0.84)×0.08/0.02)^2≈126 个独立试样；按 15% 无法评估/来源不清准备约 149 个，拟取 200 给出余量。这只是规划假设，不是观察到的效应，也不解决多次采购策略的方差。运行包内功效脚本并对标准差 0.04/0.08/0.12、效果 0.01/0.02/0.03 做情景表。

关键类事件率可能很低。若 200 个试样只有 20 个关键阳性，H2 区间仍可能太宽。应独立规划关键阳性富集敏感性集并明确其非总体抽样性质，或增加连续入组样本；不要用像素数伪造检验功效。重复采购轨迹建议 10 个独立运行/池块，至少 5 个才有初步方差线索；同一池的 10 个随机种子不能等同 10 个独立现场样本。

## 4. 专家研究与动作执行

### 4.1 专家组织

至少 3 名具有相关影像判读经验的专家独立初读，记录经验年限、任务相关资质/训练与来源单位，论文用匿名编号。初读看不到他人结果、模型预标和行动建议，使用统一显示条件与类别词典。先做约 20 个不进入正式分析的培训案例，讨论任务定义后冻结手册；不得在正式案例中通过共同讨论预先消除全部自然分歧。

20% 的案例在至少 14 天后随机混入重读，不展示原标签，记录读片顺序和会话。重复读片用来区分个人不稳定和专家间系统差异，同一个人第二次读片不是新的独立投票者。每 45—60 分钟安排休息并记录，不把疲劳与策略效应混淆。测试参考组与动作实施组人员尽量独立；人员不足时记录交叉并做留专家分析，不能写“独立专家验证”。

### 4.2 必填内容

每个指示记录对象存在性、框/多边形或掩膜、可接受的边界不确定带、类别及候选类别、确定性、所缺信息、是否可能与相邻指示合并、显示参数与用时。无指示图也必须明确完成观察，不能把空文件自动当正常。类别未知、边界不确定、画质不足是合法结果，禁止强迫所有像素具有确定标签。

把“标注错误”“合理意见差异”“信息不足”分开存储。原始读片永不覆盖。动作产物以新版本追加，并指向父版本、执行者、所见信息与耗时。收集专家说明可帮助事后审计，但策略不得读取动作之后才产生的说明。

### 4.3 六类动作的主定义

| 动作 | 允许输入与目标 | 输出 | 关键限制 |
|---|---|---|---|
| new_image | 从预先采集的未标注池购买首次标注 | 新图标签及质量报告 | 原型不包含实际出现场采集成本 |
| boundary | 对已存在的指示仅修几何范围 | 新几何版本与不确定带 | 原主分析不同时改类别或增加新对象 |
| missing | 系统搜索已有图像漏掉的指示 | 新增对象、存在性确认 | “没有发现”也是有效但可能零收益的结果 |
| class | 在固定对象/几何下重判类别 | 类别、候选分布与不可判标志 | 不偷偷修边界或删对象 |
| review | 由额外独立专家完整复核 | 新独立读取与规定聚合版本 | 复核者不能假定多数即真值 |
| reimage | 获取已授权的补充成像信息 | 新视图/图像及其标注 | 仅有真实可行接口才启用，设备等成本另记 |

现实专家发现越界问题时不能强制忽略：登记 cross_action_issue，主版本只执行所购买动作，其他问题以盲态转交后续服务；若必须一起修，标为 bundle_deviation 并完整计时，不能仍算纯 boundary 样本。出于工程安全处理的正常流程继续由合作单位负责，本研究数据版本与现场决策分离。

### 4.4 时间就是实验变量

主预算 60 专家人分钟：两位专家各用 3 分钟应计 6 人分钟。计入打开/定位、理解任务、实际标注、复核、讨论、保存和必要交接；失败、无法判断和无收益动作都计入。可识别的无关电话/离席可暂停，但暂停条件统一，自动计时与人工复核均留日志。计入动作完成所需的裁决人时，不能把高成本裁决免费放到后台。

基础三专家初读、独立测试参考、策略训练数据和工具培训属于全研究成本，与各策略增量 60 分钟分开列账。主分析回答“已有相同起始资源时，下一小时如何分配”；若要声称总标注成本节约，必须加入这些基础成本与策略开发摊销并给盈亏平衡分析。

在选择前由公开报价/历史模型给出任务最大时间预算，执行后才知道实际正耗时。算法不可用实际未来耗时排序。原型用公开最大报价保证不超预算；真实任务可能超时，应保留超时人时、记录未按时交付、并在 60 分钟截点只纳入当时已完成的标签。严禁删除超时任务以美化效率。

## 5. 随机动作预实验：学习数据从哪里来

### 5.1 不能直接用专家选择习惯作“最优动作标签”

若专家总在最难病例做复核、在简单病例修边界，直接比较两类动作结果会混入难度、画质和专家差异。也不能在合成数据中读出噪声类型，命令策略学习“边界噪声就选 boundary”；这只是识别生成器规则。

正式动作训练数据来自预先定义可用动作集合内的随机分配。先按病例分歧类型、设备、画质和预计难度分层；每个病例按记录的概率抽取一个动作，由另一随机化步骤分配可执行专家。病例按冻结的抽样方案进入 pilot，记录候选集合和进入概率。若因现场约束只能非随机执行，日志必须记录理由，只用于描述或明确假设下的探索，不替代随机主数据。

### 5.2 可用动作与支持范围

已经标注的病例可具有 boundary/missing/class/review；reimage 需有实际可执行条件。new_image 主要用于未标注病例，其可用动作通常只有该项。概率为零代表结构不可用，不得用逆倾向权重补出不存在的反事实。每一行要保存完整 logging_policy_probs，所选 propensity 必须等于对应概率，概率总和为 1。建议在可行集内均匀随机，或经预登记的分层探索；任何自适应探索变更必须记录日期、状态与版本。

主实现每例随机购买一个动作，不为获取“最优动作真值”而假装获得所有潜在结果。若资源允许，可在独立标注副本/不同执行者上做小型多动作交叉子研究，但需记录学习/记忆污染和额外费用，且每个处理版本都从同一初始版本分叉。

### 5.3 下游奖励实际计算

设初始训练集为 D0，固定检测器训练程序 T、种子 s 和开发参考 E。对病例 i 的动作 a 获得修订后训练集 D0⊕(i,a)：

令 D_i^before 表示共同 seed 训练集加病例 i 的当前监督（若 i 已 active）；未标注病例在 before 不加入。D_i^after 只把该病例替换为动作完成后的真实可见版本，或在获得首次标注后加入。因此实际代码对应：

g(i,a;s)=Risk(T(D_i^before;s),E)−Risk(T(D_i^after;s),E)。

不能把已有标注病例从 before 中遗漏，否则会把“多加入一张已存在标注图”的收益误当成修订收益。

两次训练使用相同初始化、相同步数/早停规则和可审计训练集；只允许该动作导致的输入/标签变化。E 是 reward，不是 test。真实收益可以为负；不要裁成非负后再拟合，也不要把几何变动大小、专家同意率或合成 oracle 提示当成 g。

为减少奖励过拟合，policy_train 和 policy_val 的病例分离，reward 进一步按试样拆为独立 reward_fit/reward_tune 面板。当前180例原型的20个reward试样实际拆为10/10，分别产生策略拟合与调参的奖励；正式研究可扩大面板或采用预登记交叉拟合。共享同一小 reward 被查询很多次仍会过拟合，应冻结风险定义、限制搜索网格、记录查询次数，并以最终 prospective test 判断。检测器种子导致的奖励波动在部分 pilot 例上复测 3 个种子，若噪声大于典型动作收益，先增加参考集或提高训练稳定性。

### 5.4 学习模型与在线选择

输入只含动作前可见信息：检测器预测熵/置信度、已有专家数量、存在性分歧、类别分布差异、匹配对象的边界差异、图像质量、允许的来源元数据、可用动作及历史估计成本。培训者编号可用于审计/交叉组检查，主策略尽量使用经验分层等可迁移信息，避免记住某位专家身份。

原型用多输出岭回归分别拟合下游收益与 log(cost)，含动作 one-hot 与 action×context 交互，标准化仅在 policy_train 拟合。将预测 log(cost) 取指数，再乘仅由训练残差估计的校正因子，得到正值成本点估计；它不保证精确条件期望，必须在独立 policy_val 报成本误差与校准。按实际日志概率做可选逆倾向拟合加权；截断权重只作稳定化，不会创造缺失支持。此处IPW是监督拟合权重，不是IPS价值估计；1/p可能给可用动作更多的病例较高总权重，所以noIPW消融必做。用 policy_val 的标准化收益MSE加0.05倍标准化log成本MSE选择 λ，随后冻结。

候选分数 s(i,a)=预测收益/最大(预测成本,最小正成本)。预算执行每次只在动作报价不超过剩余时间且病例未购买动作的候选中选择，完成动作后追加版本并更新检测器。Full主版本在有可行且有训练支持的动作时继续花费，即使预测收益不为正；允许“不操作”的策略为待实现扩展，不与主比较混用。报价决定可行性，预测成本决定排序，真实成本只用于事后扣账。

同一案例更改后影响整个模型的预测，未来动作收益可能与固定 D0 上的 pilot 不同。这是主方法的已知近似，不可用“因果最优策略”描述。可在预算阶段/模型状态加入公共特征并做滚动随机 pilot，但新增数据与成本必须完整记录，不能用 test 补训练。

## 6. 全部基线与消融设计

执行清单以 configs/baseline_matrix.csv 为准；README 标明哪些已在 CPU 原型实现，哪些需要真实适配。无论算法多少，预先指定最强主比较为共享同一成本模型的 uncertainty_per_minute，而不是刻意只与随机选择相比。

### 6.1 基线

B0 无新增标注：固定初始检测器，提供零增量成本参考。B1 random：在可行的病例—动作对内随机抽样，单例最多一次。B2 uncertainty_per_minute：用冻结的公开分歧规则决定某例的动作，按检测不确定性/相同预测成本排序；这是主基线。B3 disagreement_per_minute：按专家分歧强度/相同成本排序。B4 cheapest：优先预计低成本，观察是否仅因购买更多任务获益。

B5—B10 为六个固定动作策略：只在具备该动作的病例中按统一不确定性排序，其他案例不可用时保留未花费预算，最终曲线沿用最后模型。固定 new_image 必须面对同一个未标注池；固定 reimage 没有真实执行条件时列“不可评估”，不能填零成本或零误差。额外设置 uncertainty+review-only，反映常见“难例送专家”的工作流。

B11 ActiveLab 风格迁移：在可定义的图像/对象分类子任务比较“新增标签 vs 增加专家标签”的公共实现/审计重现。若完整空间标注无法保持其方法定义，应列为明确的适配实验，不能随便把熵排序改名 ActiveLab。B12 DARL 风格迁移：根据论文定义补充已有标签的清洗预算；若无法复现其分类任务假设，报告文献比较与已完成的简单重标基线，不声称复现。研究不应依靠他人未核验代码能直接运行作为完成条件。

### 6.2 消融

A1 预测收益但不除以成本；A2 只用平均动作成本，不使用病例条件成本；A3 去除专家分歧特征；A4 去除图像质量/信息不足特征；A5 合并三类分歧为一个数；A6 去除 action×context 交互，只学各动作均值；A7 不使用倾向权重；A8 只允许新增图像与通用复核；A9 逐一去除 boundary/missing/class/review/reimage/new_image；A10 把多数表决当唯一训练标签与保留不确定/软标签比较；A11 同时报告不含所有基础成本与全研究成本；A12 固定初始模型收益对滚动状态收益。

核心必做为 B0/B1/B2/全部可用固定动作、Full、A1/A3/A5/A6 与逐一去动作。其他列为扩展，不能因为资源不足静默删除后仍称“完整消融”。真实 reimage 不可行时整个研究范围明确减为五动作；模拟 reimage 保留为接口检查而不用于真实论文的主贡献。

### 6.3 公平性

所有策略共享初始数据、模型初始化分布、可用动作规则、同一物理候选池分布、成本口径、检测训练与阈值、预算检查点和锁定测试。策略开发算力与专家成本单列，不能只报告执行时的一小时。预测模型更新频率一致，若一次动作一重训过贵，则所有策略以同样预登记的批更新规则运行。

模拟可以用相同 seed×case×action 的潜在结果进行配对，降低比较噪声；真实世界不能将一位专家看过另一策略修订后的记忆当作独立执行。前瞻研究按专家/池/时段块随机分配策略，或者准备独立副本并平衡顺序。实际可行的主比较先只保留 Full 与 B2 的并行随机块，其余策略作为配对离线/次级研究，清楚区分证据等级。

### 6.4 代码中已经实现的17项CPU矩阵

configs/matrix.yaml 与 scripts/run_matrix.py 可执行：initial_only、random、cheapest、uncertainty_per_minute、disagreement_rule、六个固定动作、learned_full、without_disagreement、action_only、without_propensity_weighting、without_cost_ranking、without_logcost_residual_correction。initial_only用no_action将基线延续到共同预算；这些名称是矩阵variant，不全部等于策略API名称。共享已实际重训得到的pilot日志，分别拟合需要的策略，所有variant时间线锁定后才统一评估test/device_test。

可在完成smoke后用 --pilot-dir 复用其随机日志，避免重复生成开发奖励。17项矩阵和4策略smoke是软件验证范围；ActiveLab/DARL适配、合并分歧、去画质、逐动作排除等在CSV中明确标为待接入/额外实现，不能声称本包已经复现所有正式扩展。完整论文的机制要求与已提供最小代码边界同时保留。

## 7. 训练方案与参数

### 7.1 CPU 参考实现

图像 48×48，分为 8×8 patch 网格；三类 softmax 线性分类器/分割器在实际可见标签上优化。初始/动作后训练均执行真实 NumPy 优化，不使用真值掩膜训练。示例 180 个试样分为 32/32/16/20/32/16/16/16，依次对应八个角色。policy 与 acquisition 部分案例初始无标签，只能选择 new_image。每个有标签案例至少 3 个模拟专家读取。

smoke 配置：detector epochs=60，learning_rate=0.04，训练 class_weights=[1,3,4]；评估 weights=[1,1,3]，两者目的不同，不应误认为同一参数。策略 ridge_grid=[0.1,1,10]，cost_residual_correction=true，最小预测成本 0.05，逆倾向最大权重 10，主预算 20 模拟人分钟。foreground_threshold=0.35、component matching IoU=0.5 只是演示默认值。最终可运行参数以包内配置与运行日志为准。

软件检查验证：公开数据不含 oracle 真值；各角色物理键不相交；随机动作概率有效；成本为正；总成本不超模拟报价约束；模型实际重训；测试不进入策略循环；空分母指标为 null；失败动作仍扣费；nAUC 只使用已完成模型。合成成绩可以下降，不能改生成器以制造 Full 必胜。

### 7.2 真实首选实验

先固定一个已验证的检测/分割后端，不同时发明新骨干。建议在单张 RTX 4090 24GB 上试用中小型检测器或分割器，采用领域适配的分辨率与切块。若只有框，主检测用对象级定位指标；像素风险只能在有真实掩膜参考的子集使用，不能把框内全像素当真实缺陷。六类操作如何作用到框、多边形、类别和图像输入，在适配器里分别实现。

阶段 A 用冻结视觉编码器+小型预测头做可重复的奖励测量，首先验证动作成本与收益是否可学；阶段 B 用固定真实检测器从同一初始权重作受控微调，复核结论是否转移。若只完成阶段 A，论文就称固定特征任务研究，不写通用检测器改进。增量微调与完全重训可能得到不同动作排序，应在预登记子集比较并报告。

建议初始搜索范围：输入边长 640/1024；batch 4/8/16 由显存确定；AdamW 或后端推荐优化器固定其一；初始学习率 1e−4/3e−4/1e−3；weight_decay 1e−4 或 1e−2；训练 50—100 epoch，早停耐心 10，验证标准只看 detector_val。先用 200 个优化步测显存与吞吐，再锁定配置。表中为候选范围，未验证任何某型 YOLO 在此机器的速度，也未安装真实训练依赖。

增强仅保留符合成像规律且不会改变缺陷语义的变换，记录旋转、翻转、灰度、裁切参数；不要对细长低对比指示任意强模糊/擦除。所有策略使用相同增强、训练步数、每类采样和阈值。训练随机种子建议 [17,29,43]，主效应对种子平均，单独列方差，不选最好的一次。

## 8. 指标、图表与统计流程

### 8.1 主风险定义

合成/有可靠掩膜的任务使用可解释的有界风险。对图像 i 中真实存在且可判的类别 c，e_ic 为该类真实像素被预测为其他类别的比例。类别 0 背景的错误就是前景假阳性。r_i=Σw_c e_ic/Σw_c，求和只包括该图中出现且已知的类别，w=[1,1,3]。未知像素255不参与；整图未知则风险未定义并报告原因。先平均同一试样全部原图风险，再对试样等权平均，防止切块多的试样得到更大权重。

权重与关键类由专家在查看比较结果前锁定。真实任务若选择对象级代价风险，须在预注册时替换全流程，并使 reward 与主终点一致；不得在看到结果后把改善最大的指标改成主指标。mAP、Dice、IoU、类别混淆、校准误差和边界误差作为诊断。

### 8.2 风险—专家分钟曲线

横轴为累计已消耗的专家人分钟，纵轴为固定 test 队列的风险。必须保留 t=0 基线；只有动作完成、修订标签加入训练并获得新模型后才有新状态。两次更新间使用前一模型，最后状态延续到共同 60 分钟；不使用线性插值预支尚未产生的收益。nAUC=(1/60)∫0^60 Risk(t)dt，越低越好。15/30/60/120 分钟是预算检查点，60 是唯一主要时限。

### 8.3 安全相关代理与独立参考

critical_miss_rate 为真实含关键类的图像中完全没有预测关键类的比例；false_clear_rate 为真实有任意指示但预测全背景的比例；critical_instance_recall 按冻结 IoU 一对一匹配组件作为补充。分母、未知参考比例和不可评估例必须同时报告。这些是图像代理，不是结构失效概率、工程风险率或验收合格率。

测试参考由独立专家先独立读取，再对分歧做盲态裁决；保留不可判区域、反对意见和辅助信息。裁决不是客观物理真值的保证。可对有合法后续验证的信息作敏感性研究，但不能只验证模型说“有问题”的病例而忽略阴性验证偏差。参考组不得知道哪个策略的输出。

### 8.4 统计与呈现

每个试样计算配对策略差，主报告效应量、95% CI 和预注册检验，方法详见统计附录。测试试样 bootstrap 给出“在这些已训练策略轨迹条件下”的抽样不确定性；要对动作分配本身泛化还需多个独立采购运行，采用运行/池块及试样的层级重采样或配对块分析。不能把 5 个预算点×3 个种子×200 图像当 3000 个独立样本。

主要图：数据/专家入组流程；三种分歧与重复一致性；动作成本分布和失败率；60 分钟风险曲线；nAUC 与关键漏检森林图；动作分配随预算变化；预测收益/成本与实测残差；固定动作/消融矩阵；跨设备与跨专家效果；负收益和不可判案例。所有图若来自合成运行，标题明确“合成软件演示”，不得用“实验验证了”描述真实性能。

## 9. 里程碑、算力与人力

建议 12—16 周，由 1 名研究生负责数据工程/实验，1 名导师负责设计审查，≥3 名领域专家负责读取，另安排独立参考人员。按阶段门推进，未通过不盲目扩充模型。

| 阶段 | 周期计划 | 完成条件 |
|---|---|---|
| 任务与来源冻结 | 1—2 周 | 许可、分组键、类别词典、成本口径、设备计划完成 |
| 专家培训与小 pilot | 2—3 周 | 20 培训例；30—60 随机动作例；修订计时与可用动作 |
| 真实分歧采集 | 3—6 周 | 约 300 分歧例及未标注对照，原始读取和重复读取齐全 |
| 奖励/成本建模 | 2—3 周 | 实际重训奖励、支持范围、负收益与噪声审计 |
| 冻结与前瞻比较 | 2—3 周 | Full/B2 随机池块预算试验，测试未被调参 |
| 统计、失效分析和论文 | 2 周 | 全部 CI、负结果、成本及参考不确定性公开 |

人力估算应在 pilot 后更新。若 300 例每名专家初读 4 分钟，3 人即 3600 人分钟=60 小时；20% 重读再约 12 小时。若 360 个动作日志平均 8 人分钟，再 48 小时；独立 reward/validation/test/device_test 共 500 试样，每例 3 人×4 分钟约 100 小时，另加裁决、培训、组织和失败，整体可能 250—400 专家小时。这里均是预算情景，不是实际计时。若只拿得出 60 专家小时，就不能承诺完整 1500 试样版本，应缩为可行性研究并降低外推强度。

算力先以 200-step 基准测量。若360个动作各自需要before/after两次训练，则是720次fit；只有完全相同的训练集、种子和配置可复用before缓存，不能默认一半训练免费。假设轻量头每次fit 1—5分钟，720次约12—60 GPU小时；假设真实检测器每次受控fit 0.5—3小时，则约360—2160 GPU小时，3个种子再乘3。此量级说明必须先冻结模型、缓存公共特征并只对预登记子集做昂贵验证。未在全后端复测的结论限定为固定特征阶段；不将代理奖励伪称真实全检测器收益。前瞻每次更新训练、所有基线和消融还要额外计入；不可写“一张4090一周必然跑完”。将GPU小时、CPU时、峰值显存、存储、专家小时分别入账。

主预算是专家时间，不包含 GPU 计算；但若模型更新需要几小时，真实下一任务可在批次边界选择，报告端到端墙钟与延迟。不能将离线一次动作一重训的结果解释为实时临床/工业工作站性能。

## 10. 风险、替代路线与停止规则

数据来源键缺失：先做相似图聚类和来源核查；无法恢复物理来源时停止外部泛化主张，保留数据质量/方法可行性实验。专家资源不足：先两专家筛查+第三专家覆盖所有研究子集，主报告仍仅使用≥3独立读取子集；不能把模型当第三位专家补足。动作重叠严重：执行手册增加越界标志，主分析按意向处理保留随机分配，另做依方案敏感性；不要事后重命名动作以改善收益。

无法获得重拍：禁用真实 reimage，在论文明示可用五动作范围，并将信息不足的保留/转交率作为诊断。类别过少：仍可研究边界/漏标/复核，但不能宣称类别动作价值已验证。收益信号弱：扩大独立 reward、固定训练噪声、降低策略容量；若仍无法预测，不以任意新网络掩盖，应报告哪些动作在何种分歧下不值得额外人力。

极少关键阳性：增加事件支持或把保护性分析判为不确定；不将“零次观察漏检”写成“不会漏检”。专家间系统偏好：做留专家、分组校准和原始意见敏感性，谨慎使用多数标签。成本模型跨场所偏差：用新场所少量随机计时校准，成本校准与性能评估分离，不能以实际未来成本回填策略。

如果 Full 在冻结测试上失败，保留原注册主要结果；可以在后续新数据上研究失败机制，但新尝试需要新版本、重新冻结和新的测试。发现分组泄漏、test 驱动调参、动作日志不可追溯，相关比较必须撤回并重做，不能靠附录声明修饰。

## 11. 研究生每日执行清单与提交标准

每天开始前检查：当前数据角色、待执行动作、专家盲态、计时版本、保存路径与预算。动作完成后核对：原始版本未覆盖、执行者与输入信息记录、正耗时、失败/越界原因、结果文件 hash。训练前核对：初始权重 hash、种子、允许角色、未知区域处理、没有 test 或 oracle 路径。分析前核对：策略配置已冻结、主终点与时限没有变、全部策略与失败运行都在清单中。

每周交付一个固定格式研究记录：完成哪些样本/动作；每类数量与缺失原因；专家人时与 GPU 账本；分组审计变化；预实验发现的噪声/成本问题；版本变更理由；下一阶段的停止/继续决定。教师检查的是可复核证据和偏差，而不是漂亮的性能曲线。

投稿前最少交付：可公开的去标识数据 schema/划分 hash；完整动作定义和时间口径；匿名专家与重复读取统计；随机化/倾向概率日志；固定模型/策略参数；主要和所有计划次要结果；参考不确定性及外部泛化限制；可复现合成测试；真实适配版本与不可公开数据的获取程序；不成功的动作/策略和资源账本。没有完成的真实部分必须明写 NOT_RUN_REAL_EXPERIMENT。
