# 附录 B：数据来源、样本谱系与防泄漏操作手册

状态：研究计划。包内实际可生成的是合成数据；真实 SWRD/合作单位图像、三专家读片和动作日志需要按本附录取得。本附录不声明已下载任何完整真实数据集，也不将网上公开可见等同可再分发。

## B1. 数据取得顺序

先建立来源登记再复制图像。每个来源登记 source_id、机构、联系人角色、获得时间、原始目录/压缩包hash、许可文本版本、科研范围、是否可再分发、原始位深、文件格式、已知设备和物理试样键、是否经过滑窗或增强。个人/机构身份信息另存受限表，公共实验使用匿名键。

SWRD 论文 [R02] 是可核验数据来源，官方论文给出的下载入口与作者 GitHub 后续入口均可在 references 找到。执行者先查看当前数据说明与授权条款，下载后保存文件清单与hash。公开多边形标签可作起点，但不能写“已包含三专家分歧”；需重新邀请专家独立标注。本研究不在 ZIP 里转存受限真实图像。RapidX [R03] 当前工具源码与许可需要单独审核，详见真实接入附录。

合作单位数据先使用已授权的历史影像或正常工作流程产生的材料。要求原图与裁切映射、试样/焊缝/采集批次/设备ID及必要的采集参数。不能把工件编号直接公开，也不能因保密删除所有分组键；应由单位给出稳定的不可逆映射供研究划分。缺元数据不是简单填随机字符串即可解决。

## B2. 谱系键和连通分组

必须追踪六种关系：同一物理试样；同一条焊缝；同一原始射线图；同一采集会话/重复曝光；裁切/旋转/增强衍生；重复导出/近重复。把关系构成图，任何一条关系连通的记录作为一个 split_group，再整体分配角色。这比“按文件名随机8:1:1”更保守。

建议字段：

| 键 | 含义 | 典型错误 |
|---|---|---|
| specimen_id | 物理试样匿名键 | 每个切块发一个新试样ID |
| weld_id | 同一焊缝/焊接接头 | 同一长焊缝按图号拆开 |
| source_image_id | 原始未裁切影像 | 增强后另起原图ID |
| acquisition_session | 同次/相关采集会话，与schema及分组代码的字段名一致 | 重拍图未关联 |
| device_id/site_id | 设备及机构 | 仅记录图像尺寸当设备 |
| parent_image_id/transform | 衍生父图与变换 | 旋转/裁切后丢失坐标 |
| specimen_provenance_verified | 物理映射是否可靠 | 猜测来源后写 verified=true |

如果同一焊缝的不同试样键实际连通，使用联合组而不是挑一个键。若过大连通组导致划分不平衡，应报告限制和重新采集，不可拆组凑比例。设备独立测试还要求 device_test 的设备集合与其余角色无交集；相同型号不等于相同设备，不同序列号也不自动排除同一机构流程偏差。

## B3. 可执行划分步骤

1. 冻结原始数据登记表，核对物理键；先归并相同文件hash，再进行近重复/裁切来源核查。
2. 在有设备外部评估的前提下先保留整个外部设备/单位；这批数据不参加初始模型、阈值、动作训练或开发奖励。
3. 对剩余连通组按机构、设备、类别、画质进行分层整体划分，分配八个角色。分层信息来自入组登记或预先冻结的粗筛，不能来自模型最终错误。
4. 生成 split_manifest 及hash，记录随机种子、算法版本、每组数量、每设备分布和独立试样数。
5. 执行自动角色交叉检查与人工来源复查；任何同一物理/谱系键跨角色即失败。
6. test/device_test 图像和参考标签交由独立评估路径；训练/策略程序的文件权限或数据加载白名单只开放所需角色。
7. 需要更改划分时先记录理由、撤回旧比较并生成新版本。不得因为 test 太难把某些试样挪回训练。

训练增强在划分完成后生成，衍生文件继承父记录的split_group。模型预训练中是否见过公开 SWRD、论文模型是否使用相同数据，都列为潜在重叠；不能知道就写“未知”，不可默认干净。

## B4. 近重复检测的作用与限制

文件hash能检出完全相同字节；像素hash能检出不同封装的相同图像；感知hash/图像相似性可提供近重复候选；滑窗重叠需利用父图坐标和原始图像。任何自动阈值只能产生待核对清单，既不能证明没有物理泄漏，也不能把外观相似的不同焊缝强制当同试样。

人工审计至少抽每来源/设备若干组，查看原始资料、切片边缘、嵌入文字、曝光标志和采集时间。若试样键完全无法恢复，把该来源限制为训练/预实验；可另做“图像级划分”的透明补充，但不能将其性能当独立试样泛化。被判重复的记录不能删除后失去关联证据，应保留 excluded_reason 与父键。

## B5. 自然分歧采样与选择偏差

连续队列先按预定时段/批次全收或随机抽样，再作独立初读，估计自然分歧率。富集队列在初读后按分歧类型抽样，确保边界、类别、漏标和信息不足均有样本；记录 inclusion_reason、selection_probability 和原候选总数。临时挑“模型很容易改好”的案例会夸大收益，应禁止。

同一试样多个图像可进入同一角色，但主风险先试样内平均，不能通过多切一张图提高它的权重。超多视图病例可以预先限制每试样图数；选择规则在看标签前固定，未选视图依然保留谱系。对象数量、正负比例和关键类构成按试样和图像分别报告。

new_image 未标注池与分歧池来源分布需要可比。若未标注池全来自新设备而修边界池来自旧设备，策略选择同时承担域选择效果；应记录并在随机块中平衡，而不是把域收益称为边界动作无价值。信息不足导致 reimage 可用性时，选择机制需入可用动作与上下文记录。

## B6. 独立参考、未知标签与验证偏差

reward/detector_val/test/device_test 的参考必须分别建立，并记录原始独立读片、裁决、不可判区域。构建参考的人可以使用协议允许的辅助信息，但相同角色内条件应一致；若只给某些模型错例额外视图，会造成差异验证偏差。评估 reference_version 一旦冻结，所有策略用同一版本。

测试参考多数意见不是物理真值。可保留 soft reference 或多个合理版本进行敏感性分析：共识可判区、并集/交集边界、独立专家各自参考、unknown 极端边界。主结果使用预登记参考；替代参考用于检查结论是否依赖某一种聚合。不允许以模型最一致的专家为“最好真值”。

未知像素用255，未知类别保留unknown；禁止映为背景0。整图无法评估记录 excluded_from_metric_reason，同时保留其入组和成本信息。未知比例如果随设备/严重程度变化，必须报告；简单忽略未知只能解释为“可判区域条件下表现”。

## B7. 版本与访问矩阵

公共数据对象只包含图像、现有标注、可用动作、公开报价和允许元数据。私有真值对象只被合成环境与评估器读取；策略特征不得包含 corruption_type、true_class、optimal_action、future_cost、oracle_mask 等字段。真实数据没有可直接访问的完美 oracle，应通过完成后的 expert event 返回新版本。

初始标签 v0；每个动作产生 parent_version→child_version；未变区域也可共用文件但要写hash。删除旧标签会破坏反事实比较，必须禁止。训练集版本由一组图像/标注hash决定，模型文件记录该版本；model_before/model_after 没有版本映射时无法证明奖励来自单一动作。

分支实验从相同 v0 分叉。真实动作副本若由同一人执行，记录其已见信息；模拟潜在结果可保持相同 case/action 的结果，但不能假称真实世界已观测所有动作潜在结果。

## B8. 真实数据转为包内 schema

最小 manifest 为 JSONL，每行一个图像。需要 image_id、image_path、specimen_id、weld_id、source_image_id、device_id、site_id、split、width、height、is_synthetic、initial_labeled、annotations、available_actions、action_quotes_minutes。路径相对 manifest 所在目录。初始未标注例 initial_labeled=false，annotations=[]，一般 available_actions 只有 new_image；已有标签的同例不再作为首次标注。

每个 annotation 指向独立 labelmap 文件并给 annotator_id/read_id/is_repeat。真实框/多边形原件放在额外原始对象表；为了原型接口栅格化时保留转换脚本、尺寸和类别映射。框栅格化只能用于框监督原型，不能宣称真实像素掩膜参考。坐标使用半开/闭区间的选择要在适配器里固定，并做边缘对象测试。

真实原图可能16位；科学计算保留原位深，不得先截成8位再忘记说明。显示图与模型输入可有预处理，但记录参数。不存在的设备ID填null并在分组审计中阻止严格外部声明，不用unknown字符串把所有不明设备误当一个已知新设备。

## B9. 数据入库验收表

必过：文件存在且非空；尺寸/位深匹配；掩膜类别合法；图像/标签坐标一致；独立专家计数正确；重复读片未增加独立专家数；物理/谱系分组无跨角色；单独外部设备检查；未标注例无隐藏标签特征；引用路径不会越出授权目录；同一版本hash稳定；可用动作与报价一致；所有时间正且可追溯。

人工必过：首读盲态证据；来源元数据真实性；类别词典被所有专家理解；unknown的真实使用；未完动作与失败没有丢弃；病例进入试验的概率/理由；文件许可和再分发范围。自动schema通过不意味着这些条件已经满足。
