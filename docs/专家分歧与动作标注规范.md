# 附录 A：专家分歧、动作执行与人时记录规范

适用范围：Idea 02 的自然专家分歧与标注行动研究。此表单体系是待实施协议；所有演示专家均是模拟，不能代替有任务经验的真实专家。原始图像只用于科研的图像判读与模型研究，现场工程处置由合作单位现有流程负责。

## A1. 人员角色和盲态

设置四类角色：数据管理员、独立初读专家、动作执行专家、测试参考专家。数据管理员持有试样/设备映射，不参与策略选择。独立初读专家至少 3 人，先分别给标签；动作执行专家知道当前购买的任务，但尽量不知道策略名称和对比假设；测试参考专家不知道策略、模型置信度和其他组选择。一个人兼任角色时逐例登记，不能在论文中称其全部独立。

为每位专家生成匿名 annotator_id；另一份受限表保存经验年限、培训记录、任务相关专业背景、单位、显示设备、是否接触过病例。不要把身份明文放在公共模型输入。使用原始读取的研究版本；若现场已有报告，首读阶段屏蔽其结论与标记，同时保留必要的厚度/成像元数据。屏蔽哪些信息须跨专家一致，不能让某组享有额外背景。

培训步骤：先读任务词典；使用 20 个不进入训练/测试的例子练习工具；逐项练习 unknown、不确定带、相邻指示拆分和漏标；每人独立提交后讨论规则；冻结版本、日期和培训时长。正式阶段保留真实分歧，不能每做十例就集体协商改标签再当独立意见。

## A2. 单次读片顺序

1. 系统分配去标识 image_id，显示原始图像尺寸与统一的初始窗宽/窗位；计时开始包括打开和定位。
2. 专家先判断图像是否可判，标记局部无效、裁切、低对比、饱和、遮挡或缺元数据；这是质量意见，不自动删除病例。
3. 在未看模型预标和他人标签的情况下搜索全部焊缝区域；标存在性，完成阴性图的明确确认。
4. 每个候选指示画粗位置，再画约定的框/多边形或掩膜；没有把握时加内外不确定边界，不强迫单一精确线。
5. 填类别、候选类别及确定性；形态可见但工程类别不可定时保持 unknown。
6. 填“还需要什么信息”：更好显示、另一位专家、原始位深、原图上下文、采集参数、另一视图、其他。信息请求本身不等于该操作一定有效。
7. 执行全图第二遍扫查，保存版本；系统记录完成、异常与总人时。保存后不能覆盖旧读片。

展示增强允许作为观察工具，但记录每次操作与最终参数；原始像素保存不变。增强后才显现的边界仍要映回原图坐标。暂时无法判断时提交不可判，而不是补一个“正常”标签。

## A3. 字段字典

| 层次 | 字段 | 规则 |
|---|---|---|
| 读片 | read_id/annotator_id/image_id | 唯一、不可复用；read_id 不暴露病例难度 |
| 读片 | is_repeat/parent_read_id | 重读标记仅供管理员与分析；界面不展示原读取 |
| 读片 | start/end/active_seconds/pause_seconds | 分别存原始时间戳和按协议计算的有效时长 |
| 读片 | image_assessable | yes/partial/no；no 必须有原因 |
| 读片 | complete_negative_review | 仅全图确实读完且没有发现指示时为 true |
| 对象 | object_id/presence | present/possible/absent；允许候选存在性 |
| 对象 | geometry_type/coordinates | box/polygon/mask；使用原图坐标，不混用缩略图坐标 |
| 对象 | inner_region/outer_region | 可选不确定带；内区较确定，外区可能范围 |
| 对象 | class_id/candidate_classes | 区分形态类别与工程类别；unknown 独立取值 |
| 对象 | certainty | 预注册有锚点的 0—3 级，或校准过的概率，不能混用 |
| 对象 | insufficient_information | 多选缺失信息，允许 none |
| 对象 | merge_split_note | 相邻点状群、线状组合等的拆合约定 |
| 审计 | display_transform/model_visible | 显示变换与是否看到任何模型提示 |
| 审计 | protocol_version/artifact_hash | 防止手册/图像版本悄悄改变 |

建议确定性锚点：0=无法形成可用判断；1=存在重要替代解释；2=倾向当前判断但边界/类别存在余地；3=在本图信息范围内相对明确。这是自报信心，不是校准概率。不同专家使用量表习惯不同，先报告各专家分布，再研究是否能作为策略特征。不得把信心3当作真值权重100%。

## A4. 三类可修正差异和合法歧义

存在性/漏标分歧：某个候选对象仅部分专家画出，或某专家完成阴性检查而其他人找到指示。先以宽松位置匹配形成候选并集，再分析“存在/不存在/不可判”；不能只在多数对象中统计漏标，否则少数专家发现的细小对象会消失。

边界分歧：只在被匹配为同一候选对象的读片间计算 IoU、中心差、面积比、边界距离及不确定带重叠。不能把一人漏掉整个对象造成的 IoU=0 全解释成“边界差”，也不能在不同对象上计算边界距离。对象匹配规则须在盲态固定，例如类别无关位置 IoU/中心邻域形成候选，再人工检查歧义匹配；事后按模型性能调匹配会引入偏差。

类别分歧：在对象存在且匹配条件满足的前提下比较类别分布，保留 unknown 与候选集。存在性与类别混淆分开。二类形态分歧与多类工艺缺陷分歧不能混成一个数。报告每类混淆与专家对，不能仅报一个平均一致率。

合法歧义：来自二维投影的重叠、渐变边界、类别词典不能穷尽、低对比或缺乏采集上下文。经过独立复核仍无法排除多种解释时保持多标签/不确定区。该类不是“必须被清洗的脏标签”。研究可以判断额外信息是否值得成本，不能把坚持少数意见的人先判不合格。

建议描述统计：对象并集上的存在性一致率；匹配对象的边界 IoU 分布；类别分歧熵；专家对混淆；自身重读变化；不可判比例与所缺信息分布。Kappa/alpha 如使用应报告类别基率与缺失处理，其数值受分布影响，不独自充当标注质量金标准。

## A5. 重复读取

随机抽取 20% 的正式分歧案例及一部分无分歧案例，至少 14 天后以新呈现编号混入普通队列。按设备、初读质量和类别分层，不只复读最难例。每位专家顺序重新随机，图像不可用明显水印告诉其“这是重读”。如果专家认出图像，记录 recognized_case=true，但不要删除以求更好一致率。

重读分析以同一人同一物理试样配对。原始标签、重读标签都保留；主策略的起始状态明确使用第一读还是预先聚合版本，不能看了稳定性结果后挑更利于方法的版本。若个人不稳定超过专家间差异，应优先修订工具/任务定义和疲劳控制，而不是推出复杂“专家信誉”模型。

## A6. 六种动作的工作指令卡

### new_image：首次标注

输入为未标注但已授权采集的候选图像。专家执行完整初次标注，记录与初读相同字段，交付首次版本。若原型或实验池只是历史未标注图像，称“购买首次标注”；只有真正新获取图像且采集成本入账时才称“新增采集”。原先没有标注的案例不能凭空给 boundary/class 动作。

失败例：无法打开原始文件、画质完全不足、缺必要视图、专家无法判读；仍计已耗人时，输出失败原因与 unknown，不把空标签当全背景。初始系统检查所需人工也计入。

### boundary：几何修订

给执行者固定对象列表与原几何，隐藏无关模型建议；任务为修正范围/位置并记录不确定带。类别默认冻结，不能通过改类别获得额外收益。多个对象时是否全部修必须在报价前固定为 per_image 或 selected_objects。

若发现原对象并不存在、邻近有漏标或类别明显异常，记录 cross_action_issue。不可在没有日志的情况下偷偷删对象/补对象。若任务确需跨项处理，标 bundled 并记录实际产物和完整成本；主意向分析仍按随机分配动作归组，依方案分析可另列。

### missing：漏标搜索

提供现有标签供定位，但指令强调全图重新搜索，尤其查未覆盖区域；交付新增对象或“本次未新增”的确定性说明。允许确认某疑似对象仍不可判。没有找到新对象不表示动作未执行，也不必强制产生改善。

对象几何/类别只能对新发现项完整标注；已有项默认不修改。记录是否出现搜索疲劳、图像上下文不足。新增的小对象对模型可能产生噪声，因此下游奖励仍由实际重训决定。

### class：类别复判

提供已匹配对象与冻结几何，执行者独立填写类别和可能替代项，先独立判断，再按协议查看前读解释。区分初次意见与查看后意见。形态能够确定但缺陷机制无法判断时保持 unknown。

类别复核并不保证改标签；“保留原类”也计时并进入日志。若标签只在类名同义词层面变化，统一词典后应视为无语义变化，不能误算修复成功。

### review：增加独立专家

邀请尚未读过该例的专家做全图读取，先看不到已有标签，完成后按固定规则与原读取合并。时间包含独立读、冲突讨论与保存，如果讨论需要两人同时参与，双方人时都算。

新增专家有其系统偏差；不能默认新增投票必然更接近真值。聚合规则可以是多数/软分布/不确定区，但在所有策略中一致。原型的模拟 review 只是实现一次新增读取版本，不具备真实资质含义。

### reimage：补充信息

先确认数据提供方已有可用的关联视图/补充图像，或者有独立批准的正常成像流程。本研究学生仅接收图像，不自行安排、操作或增加射线曝光。公开可行性字段包括是否有图像、预计人时、允许期限；选择时不能看到尚未购买的补充影像结果。

交付补充图像、关联键、成像变更、标注版本与新信息类型。原图与补充图必须在同一试样/角色。专家人时、设备占用、等待和其他费用分别记录；主60人分钟分析之外再给多资源敏感性。没有可用补充图像时可用动作集中移除，不用合成替代真实结果。

## A7. 完整人时账本

一个 event 可有多个 worker segment。每段包括 expert_id、segment_start、segment_end、pause_reason、work_category。work_category 至少涵盖 setup/open、orientation、annotation、review、discussion、export、failure_handling。完成时间取所有交付所需活动结束时间，成本取各专家有效时长之和；相同专家相互重叠的计时段不能重复累计。

示例仅说明计算方法：专家 E1 打开与理解 1 分钟、画图 3 分钟，E2 独立复核 2 分钟，两人讨论 2 分钟，则费用 1+3+2+2×2=10 人分钟；不是 8 分钟墙钟，也不是只计画图的3分钟。该例是算术演示，不是观察数据。

预报价保存 quote_created_at、quoted_upper_minutes、quote_source 和可用信息版本。执行前报价变更应留旧版；任务实际超时不得回改报价。未完成任务也保留实际 cost_minutes 和 deliverable_status。预算耗尽时停止分配新任务，尚未完成的结果只能在后续预算点纳入；若研究必须收尾，收尾人时在全账本保留。

基础初读、培训、试验准备、测试参考、策略学习用的随机 pilot 是共同开发资源，不计入每条60分钟增量轨迹，但要分别累积；论文提供“边际操作成本”和“从零建立该系统的总专家成本”两张表。若新增专家动作为提高共识而引发额外裁决，不能把裁决挪入共同成本以免收费。

## A8. 事件记录最小结构

event_id、case_id、specimen_id、split、policy_run_id、policy_version、model_hash_before、annotation_version_before；action、available_actions、logging_policy_probs、propensity；public_context_version、quote_minutes、predicted_cost_minutes；assigned_experts、assignment_randomization；实际 segments、cost_minutes、started/completed、success、failure_reason、bundle_deviation；annotation_version_after、model_hash_after、reward_split_hash、actual_retraining_reward；test_metrics 不进入事件选择界面。

selected_action 的概率来自实际分配器，不是事后用模型拟合的“像是这个概率”。专家临时拒绝任务时保留原分配、拒绝原因、实际成本及 replacement_event，不能静默重新抽一个更方便的动作。专家尚未开始时的行政取消与开始后的失败分别报告，预登记主要分析按分配意向如何处理。

## A9. 质量抽查与争议处理

管理员每周随机抽10%读取检查坐标、路径、重复文件、时间重叠和字段缺失，只修技术格式错误，不替专家改医学/工业判断。坐标越界应退回原作者确认；若导出转换造成，记录转换修复与前后hash。异常短时长不能直接删除，应核对工具记录、是否早已看过与是否漏计；异常长时长同理。

独立测试参考：≥3人先独立给原始判断，之后指定裁决会话；记录裁决参与者、依据、耗时、是否用辅助信息、保留的少数意见与不确定区。无法裁决时标unknown；将未知全部排除可能选择性删难例，因此同时报告未知比例、策略间覆盖一致性以及极端取值敏感性，不把未知区域涂成背景。

终止/重做条件：初读可见他人标注但未记录；专家实际人时缺失到无法恢复；多动作混合却无版本；重复读片被当新专家；测试参考受模型输出影响；原标签被覆盖且不可恢复。出现这些问题应登记偏离并重做相应子研究，不能仅在最终表格中删除异常病例。
