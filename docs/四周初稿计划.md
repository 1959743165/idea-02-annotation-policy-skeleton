# 四周完成论文初稿的执行计划

起点：2026-11-25。目标：2026-12-23 前形成可交导师审阅的论文初稿、可追溯的代码与图表清单。该时间表以获得授权数据、专家和可运行检测器为前提。真实实验无法按期完成时，初稿必须如实写成方法与可行性研究，结果表保留未运行状态，不使用合成结果代替真实发现。

## 第1周（11月25日—12月1日）：冻结任务与数据可行性

1. 第1—2天：确定研究对象为二维焊缝射线影像指示检测；与导师和领域专家冻结类别词典、关键类、主风险、主要基线、60人分钟预算及允许的动作。把修订写入预注册模板。
2. 第2—4天：核对影像授权、原图和裁块映射、试样/焊缝/设备/采集会话ID。生成匿名来源表和初版manifest，审核跨角色关联。缺物理键的来源限用于训练或可行性检查。
3. 第4—6天：用约10—20例完成标注导出和人时记录试运行。检查三位专家独立读取、版本保存、unknown区域和任务报价字段。确定真实检测器及评估器的输入输出格式。
4. 第7天：形成数据可行性报告、授权清单、冻结协议v1、可运行的10例转换示范。若原图授权或物理来源无法取得，向导师明确调整论文范围。

## 第2周（12月2日—8日）：真实接口与盲态预实验

1. 第8—10天：完成真实影像转换器、检测器fit/predict worker及对象级评估。保存预处理、类别映射、模型版本和哈希。用固定小样本检查边界坐标和预测匹配。
2. 第10—12天：组织三位专家独立读片，保留原始读取。记录连续队列及分歧富集队列的入组理由和概率。封存测试参考，不让策略训练读取。
3. 第12—14天：随机分配可用修订动作，记录完整分配概率、专家活动区间、失败和无变化。用相同训练设置做动作前后配对重训，在独立reward面板测收益。
4. 周末交付：真实pilot日志、成本分布、模型重复训练波动与初版样本量修订。真实样本支持不足的动作标为不可估计。

## 第3周（12月9日—15日）：主比较与图表

1. 第15—17天：锁定策略超参数、检测阈值、测试参考和分析脚本。完成学习策略与不确定性／成本基线，使用相同初始数据与成本口径。
2. 第17—20天：按独立候选池或会话块执行前瞻预算，记录每一步选择、实际人时、模型版本与失败。轨迹全部锁定后统一评估test和可用的设备留出集。
3. 第20—21天：生成风险对专家人时曲线、nAUC成对比较、最终风险、关键漏检与false-clear、动作构成、成本误差、失败分析。注明独立试样数和采购块数。
4. 周末交付：主结果表和图1—3，连同每张图的输入文件、脚本、随机种子、模型哈希。未完成的外部方法和设备外实验在表中标状态。

## 第4周（12月16日—23日）：写作、复核与交稿

1. 第22—24天：写引言、相关工作、问题定义和方法。清楚区分专家分歧、标注错误和信息不足，说明六类动作与成本预算。
2. 第24—26天：写数据来源、伦理/授权、实验设置、基线、消融、统计方案、结果和局限。逐个结果回查原始日志和图表生成命令。
3. 第27天：编译LaTeX，核对参考文献、图表编号、数值方向、试样分母、合成与真实标记。请导师或合作者审阅初稿。
4. 第28—29天：修订意见并冻结初稿版本。提交PDF、LaTeX源码、代码commit、可公开的结果与复现说明。私有真实影像和可识别记录只按授权渠道共享。

## 范围与验收

- 已完成的合成CPU流程、83项单元测试和17项矩阵是软件证据；真实主结论须由真实数据支持。
- 主要优效结论需预注册的60分钟nAUC差及其区间。关键漏检只在事件数和区间足够时解释。
- 真实资源不足时，优先保证可审计的小规模pilot、真实接口和诚实的初稿。不得补造300例动作、200例测试或10个独立采购块。
- GitHub公开仓库存放代码、协议、论文源码和获准公开的结果。真实原图、专家身份、受限标签和第三方下载包留在受控存储。
