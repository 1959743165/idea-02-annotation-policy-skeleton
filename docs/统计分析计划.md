# 附录 C：预注册统计分析、功效规划和因果解释边界

版本 1.0；状态 NOT_RUN_REAL_EXPERIMENT。以下计划在真实 test 解盲前冻结。任何修改写入预注册变更表，保留旧版、理由、日期以及当时已查看的数据范围。CPU 输出属于合成软件检查，不能用来替代真实效应或本方案的功效依据。

## C1. 估计目标和独立单位

主要估计目标是在相同初始资料、模型、候选池分布和 60 专家人分钟预算下，Full 相对 uncertainty_per_minute 的平均归一化风险曲线面积差。方向统一为 Δ=Full−Baseline，负数为较好。软件 statistics.compare_trajectories 返回 B−A，调用时必须使 A=baseline、B=learned，并在输出列中保留两个策略名，避免符号反转。

条件估计与总体估计分开：给定已经完成的一组策略采购轨迹，对新的同分布测试试样的平均差，可由成对试样重采样估计；推广到未来不同候选池、专家组、动作结果和训练随机种子的策略差，还需要独立采购运行。单次轨迹+许多测试图的窄区间不能说明动作政策稳定。

当前重采样以 `specimen_id` 为簇。同一物理焊缝或母件若被登记为多个实际不独立的ID，须先规范成统一独立簇，或预注册上级簇并扩展统计实现；连通分组防泄漏通过只说明记录没有跨角色集合，并不自动证明这些ID统计独立。

推荐前瞻主比较使用 10 个独立 pool/session 块，每块平衡分配 Full 与 baseline，专家执行顺序随机。若同一病例被多策略处理，应使用独立版本与执行者并记录记忆风险。初始训练种子 [17,29,43] 在每个运行内配对；对种子平均后再做运行间比较，或采用明确的层级模型，不把种子当额外试样。

## C2. 风险计算，避免类别与大小支配

对图像 i 的真值 y、预测 ŷ，仅在可判像素 V_i 上计算。C_i 是 V_i 中真实出现的类别，背景0也算一类。e_ic=Σ_{p∈V_i}1(y_p=c,ŷ_p≠c)/Σ_{p∈V_i}1(y_p=c)。r_i=Σ_{c∈C_i}w_c e_ic/Σ_{c∈C_i}w_c；演示 w=(1,1,3)。类别没有出现时不人为加一个零误差类，不让阴性图获得虚假的关键类奖励。

同一试样 j 有 m_j 张可评估原图，r_j=(1/m_j)Σ r_i；整体 R=(1/J)Σr_j。所有已知类别的真值区域被错判都计相应误差，背景误报通过e_i0进入。未知像素255忽略，报告 unknown_fraction；某图全未知时 r_i=null。若某试样所有图全未知，试样风险无法估计并单列，不填0。策略之间必须使用同一可判参考域。

该风险不是物理失效概率。类别权重是研究成本代理；真实关键类别/权重在盲态确定，并提供 w=(1,1,1)、强调关键类的预定权重敏感性。权重变化属于探索，不能挑最好配置作为主结果。纯框检测任务需事先另定义对象级代价函数；框填满的像素风险不能等同缺陷掩膜风险。

预测阈值在 detector_val 固定。原型前景阈值0.35、组件IoU0.5是示例；真实阈值不能逐策略在test上调到同一目标召回。若要做固定灵敏度下比较，用独立验证集建立阈值并把不确定性报告清楚。

## C3. nAUC 和时间截点

设完成动作后的模型时间点0=t0<t1<…<tK≤H，风险分别R0…RK。右连续完成状态在 [tk,t{k+1}) 使用Rk；最后RK延续到H。nAUC=ΣRk×(min(t{k+1},H)−tk)/H，其中末尾t{K+1}=H。不在模型更新之间线性插值，不把完成后的改善提前分配到动作尚在进行时。

如果动作同时进行，横轴仍为累计各人所耗专家人分钟；模型何时能使用完整标签取决于交付顺序，需事先定义记账规则并按事件重建，不能用最有利的顺序。推荐主研究按任务依次采购、批次内明确完成序列。真实GPU更新时间在独立墙钟/延迟指标中报告，不能通过不记录等待使其看似实时。

t0基线必需。较早用尽可行任务的策略保持最后模型到共同60分钟，而不是用实际花费时间作较小分母。报 unspent_minutes 与任务不可用原因。超过60分钟才交付的任务在60分钟主终点不产生收益；全部实际人时仍记入成本账本和120分钟补充分析。每个预算点是同一轨迹重复测量，不作独立样本。

每个试样可计算其 r_j(t) 的 nAUC_j；固定同一测试试样集合，再形成试样宏平均。中途缺预测应恢复运行或按预注册失败处理，不能删掉不利预算点后补直线。

## C4. 主要和次要终点

| 层级 | 终点 | 比较/解释 |
|---|---|---|
| 主要 | 60分钟 nAUC | Full−uncertainty_per_minute；负好 |
| 保护性次要 | critical_miss_rate | 真含关键类而无任何关键类预测的图像比例 |
| 保护性次要 | false_clear_rate | 真含任意指示而预测全背景的图像比例 |
| 次要 | Risk@60、关键实例召回 | 固定阈值；对象匹配标准冻结 |
| 次要 | 动作失败率、耗时、未花费预算 | 解释资源与实现质量 |
| 机制 | 分歧类型/动作分配、收益残差、成本误差 | 不自动作为因果效应 |
| 探索 | 15/30/120分钟、设备/专家子组、mAP/Dice/边界 | 全部报告并标多重比较 |

critical_miss 和 false_clear 是条件于对应阳性图像的比例，分母按图像计，CI 按物理试样簇重采样；它们与试样宏风险的权重方式不同，表头要明确。分母为0时 null 并说明，绝不能报0%。关键实例召回按预定义类别、一对一IoU匹配，不把一个大预测同时匹配多个真对象。

H1 成功要求主差95%CI上界<0，且点估计≤−0.02；这并不是区间完全小于−0.02，论文需准确描述。更严格“至少改善0.02”的主张需要CI上界≤−0.02，不能混淆。H2 的探索性非劣界+0.02不是工程安全阈值；上界未低于它时结论为未证实，不等同确定有害。

## C5. 置信区间和检验

对单一锁定轨迹配对：每次有放回抽取 J 个 specimen_id，两策略取同一抽样索引，保留该试样全部图像与预算记录，重算Δ。真实主分析10,000次，给 percentile 95%CI；小样本或偏态明显可增加BCa作为敏感性，但不能看结果换主方法。假设检验可用试样级配对符号翻转/置换或适当配对均值检验，并明确交换性条件。图像二元比例的成对差同样用簇抽样，另给计数与精确/保守区间作诊断。

若有多个独立采购块，主效应先按块计算相同测试参考下的平均差，再按块配对重采样；同时用试样层重采样评估参考采样误差。若共享同一测试集，块×试样是交叉依赖，不是简单独立嵌套：可采用交叉双重bootstrap（独立重采样块和试样，再取完整网格）或混合效应模型。必须报告块数；仅2个块时再复杂模型也不能产生可靠策略总体不确定性。

多个模型种子如果仅重复优化，报告每个种子、平均及范围；不把3个高度相关种子作为3倍样本量。假设所有采购状态独立会低估不确定性，不能把action数当试样数。

主要只有一个预注册比较。H2按保护性层级报告，不以优效结论代替非劣证据。次要基线比较/消融在各预定义族内用 Holm 校正，提供原始和校正p；子组与多预算探索性可用FDR并完整列族范围。事后选择“最差baseline”作主比较是违规。

如果参考未知比例较高，报告已知区风险与范围敏感性，不将所有未知假定同一真值。交叉专家参考可以检查标签依赖，但同一批专家的多种共识不是新增独立测试集。

## C6. 功效规划

采用预先设定的成对差标准差σ_d与目标差δ。正态近似 n=((z_0.975+z_0.80)σ_d/δ)^2。取δ=0.02、σ_d=0.08得到约126个可评估独立试样；15%损失时入组ceil(126/0.85)=149。计划200仅提供余量，不能保证真实功效。σ_d必须由不接触test的pilot估计，最好给其不确定性范围。

功效入口 scripts/estimate_power.py 用蒙特卡洛模拟成对试验；默认effect=.02、paired_sd=.08、attrition=.15、alpha=.05、target=.8、repetitions=2000。输出是模型假设下的规划量，不是观察数据。至少跑δ∈{.01,.02,.03}、σ_d∈{.04,.08,.12}；报告实际命令、seed和模拟误差。如果需要临界值，按软件参数明确用正态或t近似，不混写。

该简化计算不包含专家组、候选池或多步骤动作的方差。前瞻 pilot 后为各独立运行估计Δ_run，按运行层方差重新规划运行数；同时使用层级Monte Carlo模拟测试病例和采购轨迹。若策略差主要来自池/专家，增加test图像不能替代增加独立运行。

对于 critical_miss/false_clear，功效由关键阳性事件数与策略间不一致事件决定，不能沿用风险的σ=.08。低事件率时主要报告宽CI并增加阳性样本；不得观察到零漏检就宣布100%可靠。正式非劣性研究如需要更严格结论，应另做事件驱动样本量和可接受界值的领域论证。

## C7. 随机动作日志与单步离线评估

预实验每个病例有上下文x、可行集合A(x)、分配动作a、已知概率p(a|x)、实际下游奖励g和成本c。目标策略对该病例的动作概率为π(a|x)。单步IPS=平均[π(a|x)/p(a|x)×g]；SNIPS用权重和归一；DR=平均[Σ_aπ(a|x)q(x,a)+π(a|x)/p(a|x)×(g−q(x,a))]。这些是固定病例分布下的一次动作价值，不是总60分钟风险曲线。

要求日志是实际随机分配或具有可信记录的分配概率；完整概率、动作可用性、所选概率一致；目标有正概率的动作在记录策略中也有正概率；奖励/目标策略拟合与评估试样隔离。结构不可用动作不能靠裁剪权重解决。ESS=(Σw)^2/Σw²，报告最大权重、概率最小值、每动作支持、零权重例数和裁剪敏感性。

本包 OPE CLI 的独立演示：固定ridge=1、temperature=.1，在policy_train拟合一个未使用policy_val调参的模型，再在policy_val单步评估；目标策略和q模型的训练/调参 specimen IDs 都必须与评估集不相交。主策略已经用policy_val选择λ，因此它不能再把同一policy_val当独立OPE测试；需新holdout或交叉拟合。q_provenance必须可审计，不接受“使用不同模型名字”作为独立证据。

裁剪IPW（如10）会改变偏差—方差，报告未裁剪和预定阈值敏感性，不只给最好看的数。DR不是万能纠偏：不能修复未记录专家偏好、错误概率、缺少反事实支持或看过评估集的q；不能将p(a|case)当成联合p(case,a|history)。

为什么不能用它估计预算轨迹：连续选择案例会改变剩余池、模型状态、可行报价、后续收益和停止时刻。静态日志没有联合病例选择概率与完整历史支持，简单累加IPS或用DR均值×动作数不识别该序列价值。主要证据必须来自冻结策略的前瞻预算比较。需要序列OPE时另行记录每步候选池和联合概率并检验支持，属后续扩展，当前实现不作此声称。

## C8. 缺失、失败与偏离

随机分配后即纳入动作意向分析。失败动作成本真实计入，若未产生新标签，模型状态不变；如果失败导致信息改变，保留实际状态并说明。奖励无法计算是缺失，不是零；定位原因后修复或按预注册缺失敏感性处理。真实超报价不删除，预算时点未交付不计收益，全部人时仍保留。

缺图、损坏文件和无法对应物理键在数据冻结前可按规则排除；解盲后发现的问题要报告与策略是否相关。test评估失败不允许反复换种子到成功后只保留最后一次。表格记录planned、attempted、completed、evaluable四个数量和差异原因。

## C9. 必交付分析文件

主结果表包括策略、预算、独立试样数、采购块数、种子数、动作完成/失败数、增量人时、共同开发人时、nAUC、Δ、CI、p、校正族、unknown比例及状态。病例贡献表保留specimen_id而不公开身份；成本表保留专家段而非只给均值；动作支持表包含每动作可用/被选/成功/负奖励/未知奖励数量。

预期图不预填曲线形状：Full可能优于、相当或差于baseline。所有真实表都初始化为NA和NOT_RUN_REAL_EXPERIMENT，合成输出单独放运行目录并在图名/标题标识。完整报告失败方向与估计区间，比只报告一个达到显著性的指标更有研究价值。
