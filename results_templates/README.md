# 真实研究结果模板

本目录所有结果尚未取得。NA表示未观测/未运行，不能当0；NOT_RUN_REAL_EXPERIMENT表示未开展对应真实研究。数据入组计划的数量、60分钟预算、14天重读间隔是计划参数，绝不是完成数量。合成smoke的数值只存运行/检查目录，不复制到这些表中冒充真实结果。

填写顺序：先冻结预注册 → 入组与谱系审计 → 专家原始读取与账本 → 随机pilot与真实奖励 → 冻结策略与前瞻采购 → 独立test统一评估 → 成对统计和失败分析。表中strategy名称对应代码或baseline_matrix.csv；计划扩展需实现/验证后才能填结果。

主结果表记录试样数、采购块数、优化种子数三个不同维度。nAUC方向越小越好；成对差统一method_minus_baseline。critical_miss与false_clear是图像代理比例，分母不能漏报。unknown比例与不可评估数不可省略。固定动作无可用病例时填NOT_APPLICABLE及原因，不能填完美0分。

专家与算力账本用真实时间戳和正有效活动段；同时专家时间相加。以不同resource_type分列初读、培训、随机pilot、策略执行、裁决、测试参考、GPU、设备与组织成本。预实验报价属于估计，实际超报价不得回填旧报价。
